# 0004. Protobuf over WSS + HTTPS

- Status: Accepted
- Date: 2026-11-21

## Context

The protocol must be versioned, compact and usable from other languages later.

## Decision

Schemas in `proto/duydas/v1`, Rust types generated by prost through `cargo xtask proto-gen` and committed (no `protoc` at build time). `buf breaking` runs in CI. Real-time events over WSS; history, uploads and auth over HTTPS. Stable error codes; unknown events ignored; N-1 version skew supported.

## Consequences

Third-party clients are possible later without committing to them now.
